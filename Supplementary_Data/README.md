**Study:** Yemen January 2020 FALCON BGP reconfiguration. **Sole author:** Ezzaldeen Al-Tayar.

## Table S6: 20,250 deterministic settings

- File: `Table_S6_IODA_2020_20250_Deterministic_Settings.csv`
- Type: UTF-8 text, comma-separated values, CRLF line endings
- 20,250 data rows + one header; 12 columns; 2,225,192 bytes
- SHA-256: `fa9720246ec52edb6770c8637f52da260856908574fb490a4d49f0e825245e12`
- Underlying evidence: author-computed sensitivity settings based on the **January 2020 published IODA AS30873 PNG image**, not the original IODA provider numeric timeseries.
- The observed derived divergence range is **45.8074–55.1698 percentage points** (rounded) across the deterministic settings.
- The settings are *not independent observations*; the range is *not a statistical confidence interval* and does not establish an end-user outage or cable-specific cause.
